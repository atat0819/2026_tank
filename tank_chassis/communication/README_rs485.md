# RS485 板间通信

两端使用第一路 P5 / USART3，1Mbps、8N1、高有效硬件 DE。
接线为 A-A、B-B、GND-GND。任务初始化注册 UART lambda，普通 DMA+Idle 接收；
处理数据后重启接收，忽略 DMA 半传输事件。UART Idle 不等于协议帧边界。

## 时序

云台每轮任务提交当前快照，收到有效回复后即可发起下一次 28 字节请求。
正常频率由控制任务周期及回复耗时决定，不再额外限制 5ms。
底盘收到有效请求后立即用 DMA 回复 12 字节裁判快照；底盘不独立周期发送。
云台未收到回复时最多等待 2ms，超时不阻塞控制任务；下一次发送仍使用最新操作。
HAL_BUSY 时保护在途 DMA 缓冲区，不排队重放旧命令。

## 云台 -> 底盘，28 字节

| 字节偏移 | 内容 |
|---|---|
| 0..1 | 78 91 |
| 2..5 | Yaw 偏移 float，度，电机失联为 0 |
| 6..9、10..13 | Vx、Vy，原遥控归一化 float |
| 14、15 | S1、S2，1..3；同时为 0 表示操作失联 |
| 16..19 | IMU Yaw float，度，[0,360) |
| 20..23 | IMU Z 轴角速度 float，度/秒 |
| 24..25 | 键盘 uint16，小端 |
| 26..27 | CRC16，小端，校验字节 0..25 |

float 为小端 IEEE754 单精度。键鼠模式速度字段归零，遥控模式键盘字段归零。
失联帧的开关、速度和键盘全部为 0，底盘立即撤销云台输入有效性。
坏 CRC、非法开关、非有限 float 均不更新数据和心跳、不触发回复。
没有有效帧时，原输入选择器的 100ms 控制超时继续生效，本地遥控优先不变。

## 底盘 -> 云台，12 字节

| 字节偏移 | 内容 |
|---|---|
| 0..1 | 91 78 |
| 2..3 | 枪管每秒冷却值 uint16，大端 |
| 4..5 | 枪管热量上限 uint16，大端 |
| 6..7 | 42mm 当前热量 uint16，大端 |
| 8 | 裁判在线标志，0/1 |
| 9 | 保留，0 |
| 10..11 | CRC16，小端，校验字节 0..9 |

数据区保持原 0x520 CAN 帧的顺序。云台校验后更新独立的 GimbalRefree485 数据和心跳。
其声明位于 `refree_receive_uart_485.hpp`，实现位于同名 `.cpp`，不依赖原 CAN 接收类。
裁判自身的在线标志与板间数据年龄是不同量；有效回复才刷新数据年龄。

两端 CRC16/MCRF4XX 参数为初值 FFFF、反射多项式 8408、最终异或 0000。
当前协议使用固定长度、帧头和 CRC，没有固定帧尾。接收解析支持拆帧、粘帧及噪声恢复。
原底盘 `gimbal_refree.cpp` 与云台 `boards_communication.cpp` 保留不变。
