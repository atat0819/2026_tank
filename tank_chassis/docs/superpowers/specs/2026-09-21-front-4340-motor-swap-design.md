# 前部 4310 替换为 4340 设计

## 背景

前部两个达妙电机对象当前变量名已经是 `front_4340`，但实际类型仍为 `J4310<2>`。驱动头文件中已经提供 `J4340` 类，因此本次工作只需完成前部实例类型切换，并保持现有上台阶控制链路稳定。

## 目标

- 将前部两个电机实例从 `J4310<2>` 切换为 `J4340<2>`。
- 保持前部电机的 CAN1、反馈 ID 1/2、发送 ID 1/2 和 MIT 控制方式不变。
- 保持现有位置/速度串级 PID、状态机、掉线恢复和安全分支不变。
- 更新前部相关注释及 CAN 路由契约测试，避免代码和测试继续声称前部是 4310。

## 非目标

- 不修改 `J4340` 驱动类已有的协议参数。
- 不调整 PID 增益、位置范围、目标角度、机械限位或力矩安全策略。
- 不修改后部 `J6248` 电机、底盘四个 3508 电机或 CAN 拓扑。

## 方案

使用驱动中已有的 `BSP::Motor::DM::J4340<N>` 实例化前部电机。只更新前部对象在头文件和实现文件中的模板类型；继续复用原有 `front_4340` 对象名、CAN 映射和调用点。将 `RtosTask`、FSM 及测试脚本中描述前部电机型号的注释/契约匹配同步为 4340。

## 验证

1. 运行前部 CAN 路由契约测试，确认前部实例绑定 FDCAN1 且反馈 ID 1/2 仍路由到 `front_4340`。
2. 运行上台阶集成契约测试，确认两个前部电机仍发送 MIT 控制命令。
3. 检查差异，确保只有前部型号声明、相关说明和对应测试断言发生变化。
