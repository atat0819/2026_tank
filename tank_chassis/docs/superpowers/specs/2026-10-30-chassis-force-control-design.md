# 四轮底盘力控设计

用户已确认：四轮驱动改为车体力控，取消上台阶前轮零电流/仅后轮驱动策略；转子到轮子的总减速比为 15.8。本次在指定工程内修改，不提交、不刷写。

控制链为原操作输入/模式 -> 目标车速 -> 三轴车体速度 PI -> Fx/Fy/Mz -> 四轮力矩/电流 -> 原功率限制 -> CAN。车速反馈来自四轮编码器正运动学，不对 IMU 加速度积分。失联、输入切换、STOP 和模式切换清除车体积分；四个轮反馈必须均在线。

新增一个专用 `MecanumForceControl.hpp`，集中当前车的几何、换算、三个 PI 状态与力分配；替代任务中使用错误的 Omni 正解/逆动力学，不重构其余通用库。电机顺序为左前、右前、右后、左后；沿用前进符号 {-1,+1,+1,-1}、侧移符号 {-1,-1,+1,+1}、旋转符号 {+1,+1,+1,+1}。侧移正方向沿用原操作约定。

轮半径 0.076 m，前后半距 0.215 m、左右半距 0.243 m，L=0.458 m。内部使用标准麦轮公式 w=Bv/r，v=(B^T B)^-1 B^T rw，tau=r B(B^T B)^-1 [Fx,Fy,Mz]^T。旧逆解带 cos(45°)，Y 和旋转目标保留 0.70710678 兼容倍率；用户后续确认 X 目标单独线性映射并限制为 ±2.56 m/s。反馈、力分配使用统一的物理单位。

名义轮端力矩常数采用 DJI M3508 P19 的 0.3 N m/A 除以名义 19:1，再乘用户确认的 15.8，总计约 0.24947 N m/A。不改变公共驱动的反馈单位。该值忽略实际传动效率，需要实车校核。按用户最新要求，三轴 kp、ki 和积分限幅均设为 0，不沿用或换算旧轮速 PID 参数；当前实现为 PI，没有 D 项。电流超 20 A 时四轮统一缩放，原 DecayingCurrent 再做功率缩放；对继续推向饱和的积分回退，允许反向误差释放积分。

三个轴积分分别限幅，前两轴单位 N、转动轴单位 N m；默认均为 0，使用积分前需要显式设置限幅。零增益默认配置不产生驱动电流。主机动态测试显式设置独立测试增益，与固件零默认值分离，并使用源码当前的 X/Y/旋转反馈滤波配置。

验收：零默认增益/积分限幅及非零速度误差下零驱动输出；正逆解和独立方向断言、合力/转矩重构及虚功一致、显式测试增益的比例响应、四轮电流比例/上限、限功率抗积分饱和、使用当前反馈滤波配置的简化动力学到速/保持/减速、V/B/C 各阶段均四驱、STOP/输入切换/轮反馈离线清零、机构命令发布和 VOFA 回归、Keil 链接成功。台架/实车方向、负载、打滑与上台阶悬空反馈不由主机仿真或编译结果证明。
