# 旋转角速度反馈滤波

用户要求降低旋转反馈噪声。沿用 X/Y 的二阶低通实现，为旋转配置独立滤波器：50 Hz、1 ms、阻尼比 0.707。轮速正解后先滤波再传给车体速度 PI；使能时 VOFA 第 6 通道记录同一个滤波反馈。STOP、输入暂停/切换和轮反馈失效时复位，停车遥测继续沿用未滤波正解。

只修改任务反馈链及相关测试、说明，不更改目标旋转速度、功率控制或用户当前 PI 参数。当前工作区 X 轴 Kp=280、Ki=2、积分限幅=10，保留；主机测试显式设置独立参数，避免依赖正在调节的固件参数。

- [x] 测试先确认原任务缺少旋转滤波器。
- [x] 接入滤波、PI/VOFA 同值和两处保护复位。
- [x] 验证正反转阶跃稳态、200 Hz 噪声衰减、停车/输入/轮反馈故障复位、现有控制与遥测回归，并检查 Keil 链接日志。

验证通过：轮方向及旋转滤波、X 轴限速、上台阶/保护、力控动态仿真、USB 力控 VOFA 和原 VOFA 发送测试。Keil `MDK-ARM/chassis_yaw_filter_build.log` 已链接并生成 HEX，0 Error(s)、5 Warning(s)；警告来自既有 `RemoteData_t` 类型定义。

不提交、不刷写。滤波的实车噪声和响应需通过 VOFA 观察；降低截止频率会加强滤波，也会增加反馈延迟。
