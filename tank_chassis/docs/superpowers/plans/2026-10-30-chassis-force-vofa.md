# Chassis force VOFA implementation plan

**Goal:** 在 CAN 任务通过 USB CDC 发送力控调参数据，注释保留原功率辨识 VOFA 采集发送段，不改变力控参数、机构控制或功率限制。

**Architecture:** 复用已有 `vofa_sendN()` 的 15 通道 JustFloat 帧和静态 USB 缓冲区。每轮任务初始化本周期快照，运行力控时记录实际传入 PI 的目标/反馈；公共循环每 5 ms 尝试发送一次，STOP 时仍采集有效轮速，USB 未连接或忙时跳过。

**Channels (1-based):** 1/2 X 目标/反馈，3/4 Y 目标/反馈，5/6 旋转目标/反馈，7/8/9 Fx/Fy/Mz 请求，10/11/12 三轴积分输出，13 合成电流缩放比例，14 控制状态（1=闭环，0=停车或输入暂停，-1=轮反馈无效），15 HAL tick 秒。停机时目标、力、积分和缩放为 0；有效反馈显示未滤波轮速正解，反馈无效时反馈为 0 并以状态 -1 标识。
