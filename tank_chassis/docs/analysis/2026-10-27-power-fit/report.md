# 四轮 3508 功率最小二乘辨识结果

两份记录联合拟合得到以下单电机系数，适配当前固件的六项功率模型：

```cpp
float poly_coeffs[6] = {
    0.331716565781f,  // K0
   -0.013552418237f,  // K1
    0.000527984433f,  // K2, fabsf(w)
    0.005487901513f,  // K3
    0.040981112818f,  // K4
    0.000005259051f   // K5
};
```

本次只新增分析脚本与结果，没有改写固件中的 `poly_coeffs`，也没有提交或刷写。

## 输入和方法

输入文件为 `E:/功率限制1.csv` 和 `E:/功率限制2.csv`，分别有 7,842 和 18,888 行，共 **26,730 行**。CSV 的 15 列与当前采集定义一致：I0 为四轮总实测功率，I1/3/5/7 为各轮带符号电流 A，I2/4/6/8 为转子 rad/s。I9 的旧模型预测与按当前代码重算结果最大只差约 0.000024 W；实测功率与电压乘直流电流最大差约 0.000009 W，支持当前通道映射。

所有行均为有限数，四轮在线位掩码均为 15。本次没有删掉任何记录，没有平滑、剔除残差异常点、施加非负系数约束或自动校正时延；每行权重相同。两份记录中分别有 458 和 2,110 条负功率记录，全部保留。

按如下四轮总功率方程构造回归矩阵，使用 NumPy `lstsq` 求普通最小二乘解：

```text
P_total = 4*K0 + K1*sum(I_i) + K2*sum(abs(w_i))
        + K3*sum(I_i*w_i) + K4*sum(I_i^2) + K5*sum(w_i^2)
```

矩阵列做均方根缩放以改善数值条件，求解后换回原单位。这不改变最小二乘目标。联合矩阵秩为 **6/6**，缩放后的条件数约 **11.80**。K0 已是单电机常数，不需要再除以 4。

第一份文件有三处采样序号跳变，缺少 63,592 个序号；原因可能是采集中断、USB 丢样或记录过程暂停，仅凭 CSV 无法确定。已收到的行仍保留，绘图在间断处断线并标记，没有插值补点。第二份文件序号连续。

## 误差比较

下表是联合系数在参与拟合的原始记录上的误差，单位 W。

| 记录 | 新系数 RMSE | 旧系数 RMSE | 新系数 MAE | 新系数 R² |
|---|---:|---:|---:|---:|
| 功率限制1 | 0.960 | 23.592 | 0.449 | 0.99088 |
| 功率限制2 | 1.272 | 27.463 | 0.797 | 0.98631 |
| 合并 | **1.189** | **26.387** | **0.695** | **0.98766** |

联合拟合的 95% 样本绝对误差不超过 **2.574 W**，最大绝对误差 **10.398 W**。这些是样本误差分位数，不是未来误差或置信区间保证。误差图见 `fit_comparison.png`；完整结果与输入 SHA256 见 `fit_results.json`。

若按任一转子 `abs(w) >= 1 rad/s` 选取运动段，共 16,110 行，联合系数在运动段的 RMSE 为 **1.522 W**；静止段较多，使全量 RMSE 更低。

同时做了按文件留出的验证：

| 拟合数据 | 验证数据 | 验证 RMSE，W | 验证 R² |
|---|---|---:|---:|
| 功率限制1 | 功率限制2 | 1.397 | 0.98348 |
| 功率限制2 | 功率限制1 | 0.991 | 0.99028 |

这证明模型在两份记录之间有一定一致性；最终联合系数仍需要新的独立记录验证。将系数转为 float32 后，当前数据上的 RMSE 基本不变。

## 参数稳定性与适用范围

| 参数 | 仅记录1拟合 | 仅记录2拟合 | 联合拟合 |
|---|---:|---:|---:|
| K0 | 0.348060418 | 0.327293575 | 0.331716566 |
| K1 | 0.155883481 | -0.037157694 | -0.013552418 |
| K2 | -0.000306238 | 0.000796408 | 0.000527984 |
| K3 | 0.005358737 | 0.005542541 | 0.005487902 |
| K4 | 0.043405331 | 0.040143706 | 0.040981113 |
| K5 | 0.000008186104 | 0.000003976564 | 0.000005259051 |

K3/K4 在两份记录间较一致；K1/K2 的单独拟合会改变符号，K2 与 K5 对应的特征也较相关。因此，这组参数应作为整体使用，不能把打印的小数位数理解为参数测量精度，也不宜仅凭某一系数的数值解释电机物理特性。

本次样本覆盖电流约 **-14.65～13.91 A**、转子转速约 **-403.69～464.96 rad/s**、总功率约 **-19.38～68.83 W**。对更高转速、电流或功率的预测属于外推，尚无这批数据的验证依据。

时间戳是功率帧接收时间，轮反馈取自任务处理时刻，还包含功率计内部延迟。动态段的尖峰误差没有通过移相或删点掩盖。当前结果描述供电电功率，不能用于声称机械输出效率或轴端功率。

## 复现

在工程根目录执行以下 PowerShell 命令：

```powershell
python "user/core/Alg/PowerControl-TestVersion/PythonProject/PythonScript/Polynomial Method/PowerFourWheels.py" "E:/功率限制1.csv" "E:/功率限制2.csv" --output-dir "docs/analysis/2026-10-27-power-fit"
```

脚本读取源码中的当前旧系数作对比，输出参数文本、完整 JSON 和对比图。所需库为 NumPy、pandas、Matplotlib。单独运行任一文件也可得到对应拟合；输入必须是相同的 15 通道格式。

回归测试：`python tests/power_four_wheels_fit_test.py`，覆盖四电机合成功率的已知系数恢复、带符号电流与转速、常数项乘 4、秩不足拒绝，以及无效行过滤、序号间断和负功率保留。
