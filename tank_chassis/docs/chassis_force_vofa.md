# 四轮力矩前馈 + 速度 PID 调试

控制链：遥控/键鼠与模式输入 → 原坐标变换和限速 → X/Y 二阶设定值规划 → 四轮目标轮速；规划加速度经 13 kg 平动模型和麦轮力分配产生前馈电流，各轮速度 PID 产生反馈电流，两者相加后统一限流、限功率，再发送 CAN。旋转惯性前馈与摩擦前馈未启用；旋转目标仍参与四轮逆解和速度闭环。

规划模型参考哈工大（威海）HERO 的《2.3 软件设计》2.3.2.2，作者影丨：[原文](https://bbs.robomaster.com/wiki/36827278/1647282?source=4)，CC BY-NC-SA 4.0。原文提供说明与片段。本工程将二阶跟随模型用于速度域：位置状状态对应车速，速度状状态对应加速度，第二阶变化率对应 jerk；解析计算加 jerk、保持加速度、减 jerk 三段，处理到达目标、满加速度和运动中反向，避免原片段零分母与位置跳变。前馈和反馈按电流相加，不沿用原片段中的误乘表达式。

调试初值集中在 `RtosTask/can_send_task.cpp` 的两个规划器构造参数：每轴最大加速度 4 m/s²、最大 jerk 40 m/s³，周期 1 ms。速度上限保持 X ±2.56 m/s、Y ±1.7 m/s、旋转 ±1.5 rad/s；旋转目标保持直接响应。X/Y 为独立轴约束，合加速度并非限制为 4 m/s²。这些是待实车整定的规划值，不代表实测附着力或功率可行性。

`MecanumForceControl.hpp` 中质量为 13 kg，前馈力为 `[13*ax,13*ay,0]`。四轮顺序仍为左前、右前、右后、左后，目标和反馈统一使用轮端 rad/s；反馈由转子 rad/s 除以精确总减速比 `268/17 ≈ 15.764706` 得到。四轮 PID 初值均为 Kp=1 A/(rad/s)、Ki=0.5 A/rad、Kd=0，积分输出限幅 2 A。参数不继承原三轴车速 PI，须结合实际负载整定。名义轮端力矩常数仍为 `0.3/19*(268/17) ≈ 0.2489164 N*m/A`，未标定传动效率。

四轮 PID 直接读取各轮速度；车体速度正解与原二阶低通保留供 VOFA 观察，不参与四轮反馈计算。当前 X/Y/旋转观测滤波截止频率分别为 50/20/100 Hz、采样周期 1 ms、阻尼比 0.707。轮速打滑/悬空时，正解不代表真实车速。

前馈与 PID 的合成电流先统一缩放到单轮不超过 20 A，再进入原功率模型、裁判/超电能量策略和电流衰减限制；不存在绕过功率限制的前馈通道。两级缩放均反馈给四轮 PID，回退继续推向饱和的积分，允许反向误差释放积分。

电脑连接主控 USB 数据接口，在 VOFA 选择 USB CDC 虚拟串口和 **JustFloat**。每 5 ms 尝试发送，最高约 200 Hz；USB 未枚举或发送忙时跳过，不等待、不覆盖在途缓冲区。每帧 15 个 float32 加帧尾 `00 00 80 7F`，共 64 字节。通道按 1 开始编号：

| 通道 | 内容 | 单位 |
|---|---|---|
| 1、2 | X 规划目标速度、滤波后的车体速度估计 | m/s |
| 3、4 | Y 规划目标速度、滤波后的车体速度估计 | m/s |
| 5、6 | 旋转目标角速度、滤波后的车体角速度估计 | rad/s |
| 7、8、9 | 平动惯性前馈 Fx、Fy、Mz（Mz 固定 0） | N、N、N*m |
| 10、11 | 本周期规划平均 ax、ay | m/s² |
| 12 | 四轮 PID 电流请求的最大绝对值（限幅前） | A |
| 13 | 限流与限功率合成电流缩放比例 | 0~1 |
| 14 | 控制状态：1=使能，0=STOP/输入暂停，-1=轮反馈无效 | 无 |
| 15 | 本轮采样时 HAL tick | s |

通道 10/11 由本周期规划速度增量除以 1 ms 得到，前馈惯性冲量与速度增量对应。7~9 只是前馈模型请求，不包含 PID 修正，也不是地面作用力测量；12 不是实际发送电流；13 不是功率百分比。四轮详细量可在 Watch 查看 `chassis_force.feedforward_current[4]`、`feedback_current[4]`、`integral[4]`、`motor_target_speed[4]` 与 `motor_output[4]`。

正常使能下松开摇杆/移动键会规划减速并主动制动；切入 STOP、输入失联/来源切换、任意轮反馈离线或无效时，保持原零电流保护，并清除两个规划器与四轮 PID。模式切换同样清除规划/PID 状态。STOP/输入暂停时，目标、前馈、加速度、PID 请求和缩放通道均为 0；轮反馈有效时仍显示未滤波正解，失效时反馈显示 0 并以状态 -1 标识。状态 1 不保证非零电流；即使四轮 PID 增益全为零，非零规划加速度仍会产生惯性前馈。

原功率辨识 VOFA 保持注释暂停，裁判/超电策略和 UART10 功率计接收仍运行。本次主机测试与编译不能替代实际轮向、负载、制动距离、打滑和参数稳定性验证；未刷写硬件。
