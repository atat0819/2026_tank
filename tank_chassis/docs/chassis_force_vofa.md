# 四轮力控 VOFA 调试

电脑连接主控 USB 数据接口，在 VOFA 选择对应的 USB CDC 虚拟串口和 **JustFloat** 协议。CAN 任务每 5 ms 尝试发送一帧，最高约 200 Hz；与外接功率计是否发帧无关。USB 未枚举或发送忙时跳过，不等待、不覆盖上一帧缓冲区。

每帧为 15 个 float32 加 JustFloat 帧尾 `00 00 80 7F`，共 64 字节。下表按 1 开始编号；软件若从 0 开始显示，编号减 1。

| 通道 | 内容 | 单位 |
|---|---|---|
| 1、2 | X 前后目标速度、反馈速度 | m/s |
| 3、4 | Y 侧移目标速度、反馈速度 | m/s |
| 5、6 | 旋转目标角速度、反馈角速度 | rad/s |
| 7、8、9 | PI 请求的 Fx、Fy、Mz | N、N、N*m |
| 10、11、12 | 三轴积分输出 | N、N、N*m |
| 13 | 电流限幅与功率限幅的合成电流缩放比例 | 0~1 |
| 14 | 控制状态：1=力控使能，0=STOP/输入失联或来源切换暂停，-1=轮反馈无效 | 无 |
| 15 | 本轮任务采样时的 HAL tick，换算为秒 | s |

通道 1~6 在力控使能时直接记录传入 PI 的数值：目标已完成坐标变换、独立限速和 X/Y 斜坡处理，X/Y/旋转反馈均经过独立的二阶低通滤波，当前截止频率均为 50 Hz、采样周期 1 ms、阻尼比 0.707。目标上限集中配置在 `RtosTask/can_send_task.cpp`：`CHASSIS_MAX_VX_M_S = 2.56f`、`MAX_VY_M_S = 1.7f`、`MAX_WZ_RAD_S = 1.5f`。X/Y 摇杆满量程分别线性映射至对应上限；旋转摇杆满量程映射至 1.5 rad/s，鼠标、小陀螺和跟随输出也统一按 ±1.5 rad/s 限幅，不再叠加旧 `Gain`、`c` 或 0.707 操作倍率。通道 6 是旋转角速度滤波后的反馈。它们来自同一轮控制周期。STOP、输入暂停/切换或轮反馈失效时复位三个滤波器。

STOP/输入暂停时，目标、力请求、积分和缩放通道为 0；轮反馈有效时，反馈通道仍显示新采集轮速的未滤波正解，不沿用停车前滤波状态。轮反馈无效时反馈显示 0，必须结合状态 -1 判断，不能解释为真实静止。

状态 1 只表示执行力控，不保证电流非零；三轴 PI 为零时仍不会驱动。通道 7~9 是限幅前的名义作用力请求，通道 10~12 是限幅反馈处理后的积分状态，不是实际地面作用力测量。发生饱和回退时，显示的积分状态不一定能直接重构本周期的力请求。通道 13 也不是功率百分比。

原功率辨识 VOFA 代码已在 `RtosTask/can_send_task.cpp` 注释保留，包括对应的局部状态声明；功率限制、裁判系统/超级电容策略和 UART10 功率计接收继续运行。USB 虚拟串口的波特率设置不改变 UART10 的物理波特率。
