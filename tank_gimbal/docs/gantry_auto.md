# 龙门架自动流程

状态逻辑在 `feeder_fsm/gantry_fsm.cpp`，任务采样、闭环和发送在 `RtosTask/gantry_task.cpp`。

任务直接通过 `gantry_fsm.Update(...)` 传入使能、反馈有效性、右键、五个限位、三台电机累计角度和毫秒时间。`Update` 无返回值；任务通过 `IsActive()`、`IsMoving()`、`IsKeeping()`、`GetTargetSpeed()`、`GetHoldAngle()` 等接口读取控制结果，PID 计算及 MIT 发送仍在任务循环中。`IsKeeping(axis)` 表示该轴处于主动位置保持，即已激活且该轴不在运动；未启动、停机或故障时为 false，流程结束后继续保持时为 true。任务中的 3508 和 DM 保持分支均显式判断 `IsKeeping`。

## 输入和顺序

S1、S2 都在中档时使用键鼠模式。原点需要 PA3、PA4 同时按下，右键松开后再按下启动一次：

| 动作 | 结束开关 | 速度规则 |
| --- | --- | --- |
| 第一次抬升 | PA0 | 100% → 50% → 10% |
| 向前伸出 | PA1 | 100% → 50% → 10% |
| 第二次抬升 | PA2 | 始终使用原速 |
| 向后收回 | PA3 | 100% → 50% → 10% |
| 向下回原位 | PA4 | 100% → 50% → 10% |

开关按下高电平，输入下拉，按下/松开都需稳定 20ms。右键使用现有 30ms 消抖，长按不重复执行，忙时点击不排队；右键不再请求视觉模式。

当前段进度 `<50%` 使用原速，`>=50%` 使用原速的 50%，`>=85%` 使用原速的 10%。每段重新计程、恢复原速；同一段中减速后不因回弹重新加速。累计角度不代替终点开关。

## 填写标定和控制参数

运动标定和 DM 控制参数在 `feeder_fsm/gantry_fsm.hpp` 的 `GantryTuning` 中逐项列为 `static constexpr` 常量，每项带中文注释；PID 直接填写 `RtosTask/gantry_task.cpp` 的 `lift_move_pid`、`lift_hold_pid` 和 `hold_angle_pid` 实例。默认 `CALIBRATED=false`，速度、PID 增益、超时等为零，禁止自动运动。

1. 在 Keil Watch 查看 `gantry_watch.angle_deg[0]`、`[1]`、`[2]`，依次为 FDCAN3 上的 3508 ID5、ID6、DM4310 ID9。
2. 分别记录两台升降电机的原点、第一次抬升终点、第二次抬升终点累计角度，以及 DM 的收回/伸出累计角度。单位为 deg，保留正负号；ID5/6 使用减速比 19 的输出轴端累计角度，即转子端累计角度除以 19。一套记录需在同一次连续编码器反馈期间完成，旧转子端标定角度需除以 19 后填写。
3. 分别填写 ID5、ID6 的 `LIFT_ID5_HOME_DEG` / `LIFT_ID6_HOME_DEG`、`LIFT_ID5_FIRST_DEG` / `LIFT_ID6_FIRST_DEG`、`LIFT_ID5_SECOND_DEG` / `LIFT_ID6_SECOND_DEG`，以及 `DM_RETRACT_DEG`、`DM_EXTEND_DEG`。程序使用差值确定行程和方向，每个动作开始时以实际累计角度建立当前段起点，所以无须每次上电得到相同的累计角度零点。
4. 填写 `LIFT_ID5_SPEED_RAD_S`、`LIFT_ID6_SPEED_RAD_S`、`DM_SPEED_RAD_S` 三个正值。ID5/6 驱动减速比为 19，速度目标、反馈和 PID 误差均为输出轴端 rad/s；若需保持原转子端速度，旧速度目标应除以 19，速度 PID 需按新单位整定。摩擦轮继续使用独立的默认减速比 1，保持转子端单位。DM 速度不得超过驱动的 30rad/s。每台电机正反向使用相同速度幅值。
5. 按注释填写五段 `*_TIMEOUT_MS`、`DM_MOVE_KD`、`DM_HOLD_KD` 和 `DM_TORQUE_LIMIT_NM`。3508 在 `gantry_task.cpp` 的 `lift_move_pid[2]`（升降运动速度环）和 `lift_hold_pid[2]`（位置保持速度内环）中分别填写六个数值：Kp、Ki、Kd、电流指令限幅、积分状态限幅、积分分离阈值；每组两行依次对应 ID5、ID6，共四套独立参数。电流指令限幅应为正值且不超过 16384。`hold_angle_pid[3]` 为位置保持角度外环，三行依次对应 ID5、ID6、DM ID9，六参数顺序相同；第四项输出限幅直接引用各轴速度上限，单位 rad/s，分别填写各自的 Kp、Ki、Kd、积分状态限幅和积分分离阈值。PID 使用项目现有按 5ms 周期累加的实现，Ki/Kd 不是连续时间系数。`Gantry_ConfigValid()` 不检查这些 PID 构造参数，需在实例化处完成整定。
6. 完成参数填写和方向/闭环整定后将 `CALIBRATED` 改为 true，重新编译。

两台升降电机按各自标定行程计算进度，以较大进度一起切换速度档位。两者进度差超过 `LIFT_MISMATCH`（默认 10%）停止；每台越出当前段标定行程 `TRAVEL_MARGIN`（默认 10%），或者反向超过该比例，也停止。

## 保持与故障

运动轴使用速度目标，静止轴保持动作切换时的累计角度。三台电机的累计角度、保持目标和行程标定均保留 deg；保持时先计算累计角度差，再乘 `pi/180` 转为 rad，送入对应的 `hold_angle_pid`，以角差为目标、零为反馈，得到 rad/s 速度目标。外环输出限幅由各轴速度上限在 PID 内部处理，同一次保持期间保留积分。三个角度外环的 Kp、Ki、Kd 当前均为零值占位，需分别整定。

3508 使用角度 PID → 速度 PID → 电流指令；DM 使用角度 PID → MIT 速度阻尼，并限制总阻尼力矩。位置保持外环使用 rad，内环速度目标和反馈使用 rad/s。DM 控制和反馈 ID 都为 9，需使用 MIT 模式。

3508 在第一次抬升、第二次抬升和下降时使用 `lift_move_pid`，复位对应角度外环和保持速度内环；前伸、后收及流程结束后的主动位置保持使用 `hold_angle_pid` → `lift_hold_pid`，复位运动速度 PID。每台电机未使用的 PID 在该周期复位，避免切回时沿用旧积分和误差历史；同一模式内保留 PID 状态。停机或故障时角度外环和两组速度 PID 都复位并发送零电流。

DM 前伸、后收使用 `DM_MOVE_KD` 并复位其角度外环；抬升、下降及流程结束后的主动位置保持使用 `DM_HOLD_KD`，由 `hold_angle_pid[2]` 产生纠偏速度。二者可独立整定，单位均为 `Nm/(rad/s)`，必须为有限正值且不超过 5；默认仍为零值占位。所选 Kd 同时用于力矩计算、限幅后的目标速度换算及 MIT 发送，两种状态共用 `DM_TORQUE_LIMIT_NM`。停机时角度外环复位，MIT Kp、Kd 和前馈力矩均清零。

三台反馈均收到且未超过 100ms、DM 返回使能状态、配置完整时才接受启动。动作超时、反馈失效、行程异常、升降不同步或下一目标开关提前按下，都会锁存故障。退出键鼠模式可复位；回到原点后重新进入并松开、按下右键，才允许新一轮。程序不执行自动找原点。

龙门架 DM 的使能重试使用 `feeder_fsm/motor_recovery_fsm.hpp` 中的 `MotorRecoveryFSM`。`Should_Enable` 接收“反馈在线且 DM 状态为已使能”的就绪标志；未就绪时首次立即请求 On，之后按 100ms 间隔重试，就绪边沿补发一次 On，持续就绪时不重复发送。配置无效、退出控制或锁存故障时禁止 On，并调用 `Force_Enable_On_Next_Check`，安全门解除后重新请求使能。运行中掉线仍锁存故障并清零控制，恢复反馈不会自动续跑动作。停止和故障路径只发送零力矩 MIT 指令，不主动发送 Off。

退出键鼠模式或遥控器掉线也会中止。停止路径将 3508 电流归零、DM 的 MIT Kp、Kd 和前馈力矩归零，**这不是机械抱闸**；垂直负载的零出力保持取决于机构自身。

`gantry_watch` 提供开关状态、反馈角度/速度、在线标志、DM 状态、配置是否有效、FSM 状态、故障原因、行程比例及速度档位，供联调观察。

## 已验证范围

主机测试通过，覆盖状态顺序、减速边界、第二次抬升例外、右键触发、故障锁存、开关消抖、FDCAN3 收发、反馈新鲜度、静止保持输出和 DM 力矩限制，以及默认未配置、未标定、无效行程和 DM 参数越界。相同正反转、多圈转子反馈下，确认龙门架累计角度和速度按减速比 19 换算，摩擦轮保持减速比 1。正负 2 deg 的保持误差按 rad 进入外环，测试检查两台 3508 的 PID 误差和电流指令、DM 的 MIT 速度指令，并确认累计角度快照仍为 deg。三个角度 PID 使用非零 Ki 验证持续角差下的积分输出、各轴速度限幅和饱和后解除误差的输出恢复。3508 四个速度 PID 使用不同 Kp/Ki 测试运动与保持的实际电流输出，覆盖模式内积分保留、切回时旧状态清除和停机时全部复位。DM 运动/保持 Kd 使用不同值及交换值测试，检查实际 MIT Kd 编码、小误差保持和大误差力矩限幅，并分别验证两个 Kd 的零值及上限检查。运动或停机时验证对应角度外环复位。`IsKeeping` 覆盖五段动作中的各轴保持状态、流程完成后的全部保持，以及未启动、配置无效和故障时不保持。共用恢复状态机接入后，连续任务周期测试覆盖首次请求、在线未使能及无反馈时的 99/100ms 重试边界、就绪边沿、安全门解除后重新使能，以及运行掉线后的故障锁存和禁止自动续跑。停机及故障后的查询结果检查确认无残留运动标志或目标速度。Keil 整工程构建结果为 0 Error(s)、16 Warning(s)，见 `MDK-ARM/gantry_shared_recovery_build.log`。未烧录，电机极性、实际行程、PID 参数和带载保持能力仍需实机验证。
