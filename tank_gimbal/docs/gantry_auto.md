# 龙门架自动流程

状态逻辑在 `feeder_fsm/gantry_fsm.cpp`，任务采样、闭环和发送在 `RtosTask/gantry_task.cpp`。

任务直接通过 `gantry_fsm.Update(...)` 传入使能、反馈有效性、右键、四个限位、三台电机累计角度、两台 3508 的反馈电流/速度和毫秒时间。`Update` 无返回值；任务通过 `IsActive()`、`IsMoving()`、`IsKeeping()`、`GetTargetSpeed()`、`GetHoldAngle()` 等接口读取控制结果，PID 计算及 MIT 发送仍在任务循环中。`IsKeeping(axis)` 表示该轴处于主动位置保持；未启动、停机或故障时为 false。流程结束回到底部后，两台 3508 为 false，发送零电流；DM 为 true，继续位置保持。任务中的 3508 和 DM 保持分支均显式判断 `IsKeeping`。

## 输入和顺序

S1、S2 都在中档时使用键鼠模式。下降原点开关 PA4 已取消，只使用 PE13、PE9、PA2、PA3。启动要求 PA3 后收开关按下、两台升降编码器在本次上电记录的原点容差内且转速低，右键松开后再按下启动一次：

| 动作 | 结束开关 | 速度规则 |
| --- | --- | --- |
| 第一次抬升 | PE13 | 100% → 50% → 10% |
| 向前伸出 | PE9 | 100% → 50% → 10% |
| 第二次抬升 | PA2 | 始终使用原速 |
| 向后收回 | PA3 | 100% → 50% → 10% |
| 向下回原位 | 反馈电流 + 两台低速 + 持续时间 + 接近原点 | 全程使用配置速度，单独限流 |

机构必须在固件启动时已经靠重力落在底部机械限位。首次两台 3508 反馈有效且低速时（不等待 DM 使能），FSM 记录两台升降累计角度作为本次上电原点；不主动向下找零，也不清零驱动的累计角度。记录可发生在遥控控制门关闭期间，后续切模式或故障恢复不会重新定义原点。若只重启主控而机构仍在高处，这个启动前提不成立。

四个开关按下高电平，输入下拉，按下/松开都需稳定 20ms。右键使用现有 30ms 消抖，长按不重复执行，忙时点击不排队；右键不再请求视觉模式。

第一次抬升、前伸和后收按行程减速：当前段进度 `<50%` 使用原速，`>=50%` 使用原速的 50%，`>=85%` 使用原速的 10%；同一段中减速后不因回弹重新加速。第二次抬升和下降全程保持各轴配置速度，下降不按行程减速。前四段仍由开关结束；下降段使用反馈堵转确认，累计角度继续用于原点容差、行程和不同步保护。

## 填写标定和控制参数

运动标定和 DM 控制参数在 `feeder_fsm/gantry_fsm.hpp` 的 `GantryTuning` 中逐项列为 `static constexpr` 常量，每项带中文注释；PID 直接填写 `RtosTask/gantry_task.cpp` 的 `lift_move_pid`、`lift_hold_pid` 和 `hold_angle_pid` 实例。当前按用户要求设置 `CALIBRATED=true`，仅放行空载试转；行程和触底参数均是假定值，不代表机械标定完成，禁止用于带载机构。

1. 在 Keil Watch 查看 `gantry_watch.angle_deg[0]`、`[1]`、`[2]`，依次为 FDCAN1 上的 3508 ID5、ID6，以及 FDCAN3 上的 DM4310 ID9。
2. 分别记录两台升降电机的原点、第一次抬升终点、第二次抬升终点累计角度，以及 DM 的收回/伸出累计角度。单位为 deg，保留正负号；ID5/6 使用减速比 19 的输出轴端累计角度；一套记录需在同一次连续编码器反馈期间完成。Watch 已换算为输出轴单位，不要再次除以 19；旧转子端标定值需先除以 19。
3. 分别填写 ID5、ID6 的 `LIFT_ID5_HOME_DEG` / `LIFT_ID6_HOME_DEG`、`LIFT_ID5_FIRST_DEG` / `LIFT_ID6_FIRST_DEG`、`LIFT_ID5_SECOND_DEG` / `LIFT_ID6_SECOND_DEG`，以及 `DM_RETRACT_DEG`、`DM_EXTEND_DEG`。程序使用差值确定行程和方向，每个动作开始时以实际累计角度建立当前段起点，所以无须每次上电得到相同的累计角度零点。
4. 填写 `LIFT_ID5_SPEED_RAD_S`、`LIFT_ID6_SPEED_RAD_S`、`DM_SPEED_RAD_S` 三个正值。ID5/6 驱动减速比为 19，速度目标、反馈和 PID 误差均为输出轴端 rad/s。摩擦轮继续使用独立的默认减速比 1，保持转子端单位。DM 速度不得超过驱动的 30rad/s。每台电机正反向使用相同速度幅值。
5. 按注释填写五段 `*_TIMEOUT_MS`、`DM_MOVE_KD`、`DM_HOLD_KD` 和 `DM_TORQUE_LIMIT_NM`。3508 在 `gantry_task.cpp` 的 `lift_move_pid[2]`（升降运动速度环）和 `lift_hold_pid[2]`（位置保持速度内环）中分别填写六个数值：Kp、Ki、Kd、电流指令限幅、积分状态限幅、积分分离阈值；每组两行依次对应 ID5、ID6，共四套独立参数。电流指令限幅应为正值且不超过 16384。`hold_angle_pid[3]` 为位置保持角度外环，三行依次对应 ID5、ID6、DM ID9，六参数顺序相同；第四项输出限幅直接引用各轴速度上限，单位 rad/s，分别填写各自的 Kp、Ki、Kd、积分状态限幅和积分分离阈值。PID 使用项目现有按任务调用累加的实现，当前任务保留 `osDelay(2)`，Ki/Kd 不是连续时间系数。`Gantry_ConfigValid()` 不检查这些 PID 构造参数，需在实例化处完成整定。
6. 实测并确认下面的下降判定参数；当前数值尚未经实测，不能作为放行依据。电流阈值应高于正常下降/制动电流，并低于可实际达到的下降限流；反馈速度使用输出轴端 rad/s。
7. 完成参数填写和方向/闭环整定后将 `CALIBRATED` 改为 true，重新编译。

| 参数 | 含义和约束 |
| --- | --- |
| `LOWER_CURRENT_LIMIT_A` | 下降电流指令限幅，正值且不超过 20 A；实际接触力需实测 |
| `LOWER_STALL_CURRENT_A` | 任一台实测转矩电流的绝对值门槛，正值且小于下降限流 |
| `LOWER_STALL_SPEED_RAD_S` | 两台输出轴速度绝对值都不超过此值，且该门槛小于两台配置下降目标速度幅值中的较小值 |
| `LOWER_STALL_CONFIRM_MS` | 高电流和双低速连续成立时间，正值且小于 `LOWER_TIMEOUT_MS` |
| `LIFT_HOME_TOLERANCE_DEG` | 两台编码器相对本次启动原点的允许偏差，输出轴端 deg |

`gantry_watch.lift_current_a[0/1]` 分别观察 ID5/ID6 的实际转矩电流 A，保留正负号，不是电源输入电流。任务中的 PID 输出仍为 C620 原始电流指令，下降限流按 `A * 16384 / 20` 换算；电流不乘除减速比。

两台升降电机按各自标定行程计算进度，第一次抬升时以较大进度一起切换速度档位；第二次抬升和下降保持配置速度，继续检查进度保护。两者进度差超过 `LIFT_MISMATCH`（默认 10%）停止；每台越出当前段标定行程 `TRAVEL_MARGIN`（默认 10%），或者反向超过该比例，也停止。

## 保持与故障

运动轴使用速度目标，运行过程中静止轴保持动作切换时的累计角度；回到底部完成后，两台 3508 依靠机械限位承载，发送零电流并复位 PID，DM 继续保持。三台电机的累计角度、保持目标和行程标定均保留 deg；保持时先计算累计角度差，再乘 `pi/180` 转为 rad，送入对应的 `hold_angle_pid`，以角差为目标、零为反馈，得到 rad/s 速度目标。外环输出限幅由各轴速度上限在 PID 内部处理，同一次保持期间保留积分。三个角度外环已填写空载起始参数，仍需分别实机整定。

3508 使用角度 PID → 速度 PID → 电流指令；DM 使用角度 PID → MIT 速度阻尼，并限制总阻尼力矩。位置保持外环使用 rad，内环速度目标和反馈使用 rad/s。DM 控制和反馈 ID 都为 9，需使用 MIT 模式。

3508 在第一次抬升、第二次抬升和下降时使用 `lift_move_pid`，复位对应角度外环和保持速度内环；前伸、后收阶段的主动位置保持使用 `hold_angle_pid` → `lift_hold_pid`，复位运动速度 PID。每台电机未使用的 PID 在该周期复位，避免切回时沿用旧积分和误差历史；同一模式内保留 PID 状态。停机、故障或下降到底完成时，两台 3508 的角度外环和两组速度 PID 都复位并发送零电流。

DM 前伸、后收使用 `DM_MOVE_KD` 并复位其角度外环；抬升、下降及流程结束后的主动位置保持使用 `DM_HOLD_KD`，由 `hold_angle_pid[2]` 产生纠偏速度。二者可独立整定，单位均为 `Nm/(rad/s)`，必须为有限正值且不超过 5；当前填写为空载起始参数。所选 Kd 同时用于力矩计算、限幅后的目标速度换算及 MIT 发送，两种状态共用 `DM_TORQUE_LIMIT_NM`。停机时角度外环复位，MIT Kp、Kd 和前馈力矩均清零。

下降过程中，至少一台 3508 的电流绝对值达到门槛、两台速度都低于门槛，才开始计时；电流或任一速度条件中断就重新计时。连续达到确认时间后，两台编码器都在启动原点容差内才结束下降，两台电机同周期清 PID 并发送零电流；若仍远离原点则锁存 `GantryFault::Stall`，不把中途卡住当作原点。超时、越行程、不同步或反馈失效优先进入故障。

三台反馈均收到且未超过 100ms、DM 返回使能状态、配置完整、PA3 按下且两台升降编码器接近记录原点时才接受启动。动作超时、反馈失效、行程异常、升降不同步或下一目标开关提前按下，都会锁存故障。退出键鼠模式可复位；回到原点后重新进入并松开、按下右键，才允许新一轮。程序不执行自动找原点。

龙门架 DM 的使能重试使用 `feeder_fsm/motor_recovery_fsm.hpp` 中的 `MotorRecoveryFSM`。`Should_Enable` 接收“反馈在线且 DM 状态为已使能”的就绪标志；未就绪时首次立即请求 On，之后按 100ms 间隔重试，就绪边沿补发一次 On，持续就绪时不重复发送。配置无效、退出控制或锁存故障时禁止 On，并调用 `Force_Enable_On_Next_Check`，安全门解除后重新请求使能。运行中掉线仍锁存故障并清零控制，恢复反馈不会自动续跑动作。停止和故障路径只发送零力矩 MIT 指令，不主动发送 Off。

退出键鼠模式或遥控器掉线也会中止。停止路径将 3508 电流归零、DM 的 MIT Kp、Kd 和前馈力矩归零，**这不是机械抱闸**；垂直负载的零出力保持取决于机构自身。

`gantry_watch` 提供四个开关状态、反馈角度/速度、两台 3508 的实测转矩电流、在线标志、DM 状态、配置是否有效、FSM 状态、故障原因、行程比例及速度档位，供联调观察。

## 已验证范围

主机测试通过：FSM 覆盖五段顺序、第一次抬升与 DM 伸缩减速、第二次抬升和下降恒速、故障锁存、启动原点只记录一次、DM 未使能时记录升降原点、切模式和故障恢复不重定原点、连续堵转的 99/100ms 边界、瞬时电流/高速排除、中途卡住、反馈失效、计时回绕，以及未填写或越界参数禁止运行。任务与真实驱动测试检查四 GPIO 采样、正负实际转矩电流的 A 换算、下降限流、到底同周期两台 3508 零电流并复位 PID、DM 继续保持，以及 no-Off 和原有门控 On 重试。输入消抖与共用恢复状态机测试通过。

Keil 整工程构建结果为 0 Error(s)、16 Warning(s)，见 `MDK-ARM/gantry_constant_lower_build.log`。未烧录；触底阈值尚待实测，当前仅放行空载试转。机械落底前提、接触力、电流阈值、实际行程与带载行为尚未实机验证；原点容差内的异物阻挡仍可能与机械止挡表现相同。

## 2026-10-25 空载低速起始配置

保留原五段开关/堵转流程，不增加点动或演示模式。3508 使用输出轴端 3/19 rad/s（约 0.158 rad/s，约 1.5 rpm），运动与保持速度 PID 均限制为 409.6 原始指令（0.5 A）；DM 使用 0.2 rad/s、运动/保持 Kd=1、总阻尼力矩上限 0.15 Nm。这些是未实机整定的起始参数，不是带载参数。超时初值依次为 30/60/30/60/30 秒，实测行程确定后须重新核算，包含既有减速段时间。

按用户要求改为假定行程并设置 CALIBRATED=true：ID5/ID6 均为 0→360/19→720/19 deg（输出轴端，约 0→18.947→37.895 deg），DM 为 0→30 deg。这些是假定差值，开机角度不必等于 0。触底电流、低速门槛、持续时间和原点容差仍是假定初值；保留原有保护，不代表机械标定完成。实际 GPIO 信号和电机方向需实机确认，装机构或带载前须换回 CALIBRATED=false 并完成实测。

实际起始 PID 与门控校验：`python -B tests/gantry_tuning_test.py`。测试只检查真实配置的输出方向、限流、复位和静态合法性，不证明闭环稳定性或机械标定正确。

空载试转操作：上电时保持三台电机静止；双中挡、遥控在线且键鼠输入有效，先按住 PA3 后收开关，松开再按右键启动。第一次抬升按 PE13，DM 前伸按 PE9，第二次抬升按 PA2，DM 后收按 PA3；离开上一阶段后松开对应开关，不要提前按下一目标开关。开关仍需在假定行程的保护范围内触发，超过 110% 行程会报错；两台升降的归一化进度差超过 10% 也会报错。空载未触底时下降无法正常结束，触发行程或超时故障属于预期保护，不要用手制造堵转。切出双中挡或断开遥控会零输出，不是机械制动。

## 输出轴单位与启动原点容差

3508 ID5/ID6 的累计角度、行程端点、原点容差统一为输出轴端 deg，速度、低速门槛和闭环误差为输出轴端 rad/s；驱动实例减速比为 19，摩擦轮实例仍为默认 1。DM 单位不变。此次单位换算保留原试转的实际速度、行程和电流响应：速度环 Kp/Ki 乘 19、积分状态限幅除以 19；位置外环增益不变、输出及积分状态限幅除以 19。电流限幅 0.5 A 不随减速比换算。

原点参考取两台 3508 收到真实反馈后的首次有效低速快照，仅记录一次；不是强制编码器读数为 0。原点容差现为输出轴 10/19≈0.526 deg，低速门槛现为输出轴 0.4/19≈0.0211 rad/s。按右键时，两个轴均须位于各自记录原点的 ±0.526 deg 内且低速；下降触底完成也使用同样的原点容差。例如某轴本次启动原点是输出轴 20 deg，允许范围约为 19.474～20.526 deg。需要更宽机械容差时，应另行按实测调整，不能把本次单位换算当作放宽到输出轴 10 deg。
