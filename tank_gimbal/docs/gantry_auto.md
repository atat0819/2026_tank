# 龙门架自动流程

当前下降仅由 PD10 结束，不再依据电流和低速判断堵转；保留超时、行程、不同步与反馈保护。下文历史记录中的堵转参数和检测说明不再适用。

## 两侧升降同步（2026-11-16）

两侧链轮和外部传动比例相同。各自 `FIRST_DEG - HOME_DEG` 的正负表示该电机向上抬升的旋转方向，允许 ID5 正转向上、ID6 反转向上，也允许其他方向组合。机构上电时必须已经在底部对齐且两条链条张紧；现有首次有效低速反馈只记录原点，不能检测机械是否对齐。

用各自累计角度减去本次上电记录的原点，再乘各自向上方向，得到同一坐标中的输出轴位移。`ID5位移 - ID6位移` 为同步误差，正值表示 ID5 侧牵引位置较高。此误差不使用各段 `start_deg_`，换阶段、切模式和故障恢复均不会重新定义对齐基准；不依赖精确终点角度作为位置目标。

第一次抬升、第二次抬升和下降在原速度控制上加入同步比例纠偏。公共速度上限取两侧 `LIFT_ID5_SPEED_RAD_S`、`LIFT_ID6_SPEED_RAD_S` 的较小值，再乘当前速度档位；两侧配置值都作为正的速度上限使用。`LIFT_SYNC_KP=1.0`（1/s）将同步角差 rad 转为纠偏速度 rad/s，`LIFT_SYNC_MAX_SPEED_RATIO=0.20` 将修正限制在当前公共速度的 20%。两者均为待实测起始值，任一个置 0 可关闭主动纠偏；增益须非负，比例范围为 [0,1]。

在向上为正的坐标中，ID5 速度为 `基础速度 - 修正`，ID6 为 `基础速度 + 修正`，最后各自限幅并换回电机旋转方向。上升时较高侧减速，下降时较低侧减速等待较高侧下降；即使追赶侧达到速度上限，等待侧的减速仍然有效。修正不会让某侧反向。第一次抬升的低速档同样限制纠偏幅度；第二次抬升和下降以配置速度为基础，但允许同步纠偏使某侧减速。

前伸、后收期间继续使用原有各自角度/速度双环保持，不额外移动保持目标做整平；同步基准和误差继续保留，下一段升降继续纠偏。原有分段进度差 `LIFT_MISMATCH`、行程、超时和反馈故障保护保留；该 10% 分段进度阈值不是已验证的机械允许高度差，需要实机复核。故障、失能和 PD10 到底后的升降零电流策略不变。

Keil Watch 查看 `gantry_watch.lift_sync_error_deg`（输出轴 deg，ID5 较高为正）、`target_velocity_rad_s[0/1]`（已换回电机方向的速度目标）、`velocity_rad_s[0/1]` 和 `lift_current_a[0/1]`。先低速空载确认方向和纠偏符号，再逐步带载观察是否出现位置差扩大或电流饱和。电机反馈不能直接检测链条松弛、跳齿和伸长。

主机同步测试：`python -B tests/gantry_sync_test.py`。当前实际行程、速度、运动/保持 PID 和重力补偿仍为零，配置校验禁止启动；新同步参数不会解除该门槛。未烧录或验证带载机械行为。

## 升降重力补偿

`GantryTuning` 中 `LIFT_ID5_GRAVITY_EMPTY_CMD`、`LIFT_ID6_GRAVITY_EMPTY_CMD` 为两台电机空载补偿，`LIFT_ID5_GRAVITY_LOADED_CMD`、`LIFT_ID6_GRAVITY_LOADED_CMD` 为带载补偿，单位与 PID 输出相同，均为有符号 C620 原始电流指令，范围 ±16384，初值全部为 0。分别确认两台电机向上的电流方向后再从小值整定；当前零值不会产生重力补偿。

第一次抬升和前伸保持使用空载值，第二次抬升、后收保持和下降开始使用带载值。下降时两台电机各自达到标定完整下降行程的 `LOWER_UNLOAD_PROGRESS`（默认 40%）后，200 ms 内线性切换到空载值；回弹不会撤销已开始的切换。该行程只是假定物品已经由车身承托，不能检测实际卸载状态。

补偿与运动或保持 PID 指令相加后，上升和下降均限制在 C620 原始指令 ±16384。故障、失能和下降到底后升降电机仍为零电流。下降不再进行电流和低速堵转判断。标定时先检查行程、方向和空载行为，再逐步检查带载及物品落在车身的过程。

状态逻辑在 `feeder_fsm/gantry_fsm.cpp`，任务采样、闭环和发送在 `RtosTask/gantry_task.cpp`。

龙门架 FSM 的角度参数、原点/保持角度、行程计算、任务角度快照及 Watch 角度字段统一使用 `float`，小数运算常量使用 `f` 后缀，与 `getAddAngleDeg()` 本来返回的 `float` 精度一致。共享电机驱动内部仍用 `double` 累计角度；本次调整不改变它的累计方式。H723 和当前工程支持双精度硬件浮点，不能将类型调整等同于必然显著加速；这里只减少龙门架的存储和混合类型转换，实际耗时未做板上测量。

任务直接通过 `gantry_fsm.Update(...)` 传入使能、反馈有效性、Z 键、五个限位、三台电机累计角度、两台 3508 的反馈电流/速度和毫秒时间。`Update` 无返回值；任务通过 `IsActive()`、`IsMoving()`、`IsKeeping()`、`GetTargetSpeed()`、`GetHoldAngle()` 等接口读取控制结果，PID 计算及 MIT 发送仍在任务循环中。`IsKeeping(axis)` 表示该轴处于主动位置保持；未启动、停机或故障时为 false。流程结束回到底部后，两台 3508 为 false，发送零电流；DM 为 true，继续位置保持。任务中的 3508 和 DM 保持分支均显式判断 `IsKeeping`。

## 输入和顺序

S1、S2 都在中档时使用键鼠模式。启动要求两台升降编码器在本次上电记录的原点容差内且转速低；先松开 Z 键，再按住 Z 键连续保持 2 秒启动一次。中途松开、控制失能或反馈无效会取消计时；动作中松开 Z 键不会中断流程。

| 动作 | 结束开关 | 速度规则 |
| --- | --- | --- |
| 第一次抬升 | PE13 | 100% → 50% → 10% |
| 向前伸出 | PE9 | 100% → 50% → 10% |
| 第二次抬升 | PA2 | 基础速度为原速，允许同步纠偏减速 |
| 向后收回 | PA0 | 100% → 50% → 10% |
| 向下回原位 | PD10 | 基础速度为配置速度，允许同步纠偏减速；PD10 结束下降 |

机构必须在固件启动时已经靠重力落在底部机械限位。首次两台 3508 反馈有效且低速时（不等待 DM 使能），FSM 记录两台升降累计角度作为本次上电原点；不主动向下找零，也不清零驱动的累计角度。记录可发生在遥控控制门关闭期间，后续切模式或故障恢复不会重新定义原点。若只重启主控而机构仍在高处，这个启动前提不成立。

五个开关按下低电平，输入上拉，按下/松开都需稳定 20ms。Z 键连续按住 2 秒触发，长按不重复执行，忙时按键不排队；右键不请求视觉模式。

第一次抬升、前伸和后收按行程减速：当前段进度 `<50%` 使用原速，`>=50%` 使用原速的 50%，`>=85%` 使用原速的 10%；同一段中减速后不因回弹重新加速。第二次抬升和下降不按行程减速，基础速度取两侧配置速度的较小值；三段升降都允许同步纠偏使某侧减速。五段均由对应开关结束，累计角度继续用于原点容差、行程和不同步保护。

## 填写标定和控制参数

运动标定和 DM 控制参数在 `feeder_fsm/gantry_fsm.hpp` 的 `GantryTuning` 中逐项列为 `static constexpr` 常量，每项带中文注释；PID 直接填写 `RtosTask/gantry_task.cpp` 的 `lift_move_pid`、`lift_hold_pid` 和 `hold_angle_pid` 实例。当前按用户要求设置 `CALIBRATED=true`，仅放行空载试转；行程和触底参数均是假定值，不代表机械标定完成，禁止用于带载机构。

1. 在 Keil Watch 查看 `gantry_watch.angle_deg[0]`、`[1]`、`[2]`，依次为 FDCAN1 上的 3508 ID5、ID6，以及 FDCAN3 上的 DM4310 ID9。
2. 分别记录两台升降电机的原点、第一次抬升终点、第二次抬升终点累计角度，以及 DM 的收回/伸出累计角度。单位为 deg，保留正负号；ID5/6 使用减速比 19 的输出轴端累计角度；一套记录需在同一次连续编码器反馈期间完成。Watch 已换算为输出轴单位，不要再次除以 19；旧转子端标定值需先除以 19。
3. 分别填写 ID5、ID6 的 `LIFT_ID5_HOME_DEG` / `LIFT_ID6_HOME_DEG`、`LIFT_ID5_FIRST_DEG` / `LIFT_ID6_FIRST_DEG`、`LIFT_ID5_SECOND_DEG` / `LIFT_ID6_SECOND_DEG`，以及 `DM_RETRACT_DEG`、`DM_EXTEND_DEG`。程序使用差值确定行程和方向，每个动作开始时以实际累计角度建立当前段起点，所以无须每次上电得到相同的累计角度零点。
4. 填写 `LIFT_ID5_SPEED_RAD_S`、`LIFT_ID6_SPEED_RAD_S`、`DM_SPEED_RAD_S` 三个正值。ID5/6 驱动减速比为 19，速度目标、反馈和 PID 误差均为输出轴端 rad/s。摩擦轮继续使用独立的默认减速比 1，保持转子端单位。DM 速度不得超过驱动的 30rad/s。每台电机正反向使用相同速度幅值。
5. 按注释填写五段 `*_TIMEOUT_MS`、`DM_MOVE_KD`、`DM_HOLD_KD` 和 `DM_TORQUE_LIMIT_NM`。3508 在 `gantry_task.cpp` 的 `lift_move_pid[2]`（升降运动速度环）和 `lift_hold_pid[2]`（位置保持速度内环）中分别填写六个数值：Kp、Ki、Kd、电流指令限幅、积分状态限幅、积分分离阈值；每组两行依次对应 ID5、ID6，共四套独立参数。电流指令限幅应为正值且不超过 16384。`hold_angle_pid[3]` 为位置保持角度外环，三行依次对应 ID5、ID6、DM ID9，六参数顺序相同；第四项输出限幅直接引用各轴速度上限，单位 rad/s，分别填写各自的 Kp、Ki、Kd、积分状态限幅和积分分离阈值。PID 使用项目现有按任务调用累加的实现，当前任务保留 `osDelay(2)`，Ki/Kd 不是连续时间系数。`Gantry_ConfigValid()` 不检查这些 PID 构造参数，需在实例化处完成整定。
6. 实测并确认原点静止速度和原点容差；反馈速度使用输出轴端 rad/s。
7. 完成参数填写和方向/闭环整定后将 `CALIBRATED` 改为 true，重新编译。

| 参数 | 含义和约束 |
| --- | --- |
| `HOME_STOP_SPEED_RAD_S` | 上电记录原点及启动时的双轴静止速度门槛 |
| `LIFT_HOME_TOLERANCE_DEG` | 两台编码器相对本次启动原点的允许偏差，输出轴端 deg |

`gantry_watch.lift_current_a[0/1]` 分别观察 ID5/ID6 的实际转矩电流 A，保留正负号，不是电源输入电流。任务中的 PID 输出及重力补偿均为 C620 原始电流指令；电流不乘除减速比。

两台升降电机按各自标定行程计算进度，第一次抬升时以较大进度一起切换速度档位；第二次抬升和下降保持基础速度档位，继续检查进度保护并执行同步纠偏。两者进度差超过 `LIFT_MISMATCH`（默认 10%）停止；每台越出当前段标定行程 `TRAVEL_MARGIN`，或者反向超过该比例，也停止。

## 保持与故障

运动轴使用速度目标，运行过程中静止轴保持动作切换时的累计角度；回到底部完成后，两台 3508 依靠机械限位承载，发送零电流并复位 PID，DM 继续保持。三台电机的累计角度、保持目标和行程标定均保留 deg；保持时先计算累计角度差，再乘 `pi/180` 转为 rad，送入对应的 `hold_angle_pid`，以角差为目标、零为反馈，得到 rad/s 速度目标。外环输出限幅由各轴速度上限在 PID 内部处理，同一次保持期间保留积分。三个角度外环已填写空载起始参数，仍需分别实机整定。

3508 使用角度 PID → 速度 PID → 电流指令；DM 使用角度 PID → MIT 速度阻尼，并限制总阻尼力矩。位置保持外环使用 rad，内环速度目标和反馈使用 rad/s。DM 控制和反馈 ID 都为 9，需使用 MIT 模式。

3508 在第一次抬升、第二次抬升和下降时使用 `lift_move_pid`，复位对应角度外环和保持速度内环；前伸、后收阶段的主动位置保持使用 `hold_angle_pid` → `lift_hold_pid`，复位运动速度 PID。每台电机未使用的 PID 在该周期复位，避免切回时沿用旧积分和误差历史；同一模式内保留 PID 状态。停机、故障或下降到底完成时，两台 3508 的角度外环和两组速度 PID 都复位并发送零电流。

DM 前伸、后收使用 `DM_MOVE_KD` 并复位其角度外环；抬升、下降及流程结束后的主动位置保持使用 `DM_HOLD_KD`，由 `hold_angle_pid[2]` 产生纠偏速度。二者可独立整定，单位均为 `Nm/(rad/s)`，必须为有限正值且不超过 5；当前填写为空载起始参数。所选 Kd 同时用于力矩计算、限幅后的目标速度换算及 MIT 发送，两种状态共用 `DM_TORQUE_LIMIT_NM`。停机时角度外环复位，MIT Kp、Kd 和前馈力矩均清零。

下降仅由 PD10 结束；若开关未触发，继续受下降超时、行程、双升降不同步和反馈保护约束。程序不再检测下降堵转。

三台反馈均收到且未超过 100ms、DM 返回使能状态、配置完整、两台升降编码器接近记录原点且低速时才接受启动。动作超时、反馈失效、行程异常、升降不同步或下一目标开关提前按下，都会锁存故障。退出键鼠模式可复位；回到原点后重新进入并松开、长按 Z 键，才允许新一轮。程序不执行自动找原点。

龙门架 DM 的使能重试使用 `feeder_fsm/motor_recovery_fsm.hpp` 中的 `MotorRecoveryFSM`。`Should_Enable` 接收“反馈在线且 DM 状态为已使能”的就绪标志；未就绪时首次立即请求 On，之后按 100ms 间隔重试，就绪边沿补发一次 On，持续就绪时不重复发送。配置无效、退出控制或锁存故障时禁止 On，并调用 `Force_Enable_On_Next_Check`，安全门解除后重新请求使能。运行中掉线仍锁存故障并清零控制，恢复反馈不会自动续跑动作。停止和故障路径只发送零力矩 MIT 指令，不主动发送 Off。

退出键鼠模式或遥控器掉线也会中止。停止路径将 3508 电流归零、DM 的 MIT Kp、Kd 和前馈力矩归零，**这不是机械抱闸**；垂直负载的零出力保持取决于机构自身。

`gantry_watch` 提供五个开关状态、反馈角度/速度、两台 3508 的实测转矩电流、在线标志、DM 状态、配置是否有效、FSM 状态、故障原因、行程比例及速度档位，供联调观察。

空载试转操作：上电时保持三台电机静止；双中挡、遥控在线且键鼠输入有效，先松开 Z 键，再长按 Z 键启动。第一次抬升按 PE13，DM 前伸按 PE9，第二次抬升按 PA2，DM 后收按 PA0，下降到底按 PD10；离开上一阶段后松开对应开关，不要提前按下一目标开关。开关需在配置行程的保护范围内触发；两台升降的归一化进度差超过 10% 会报错。空载未触底时下降无法正常结束，触发行程或超时故障属于预期保护，不要用手制造堵转。切出双中挡或断开遥控会零输出，不是机械制动。

## 输出轴单位与启动原点容差

3508 ID5/ID6 的累计角度、行程端点、原点容差统一为输出轴端 deg，速度、低速门槛和闭环误差为输出轴端 rad/s；驱动实例减速比为 19，摩擦轮实例仍为默认 1。DM 单位不变。此次单位换算保留原试转的实际速度、行程和电流响应：速度环 Kp/Ki 乘 19、积分状态限幅除以 19；位置外环增益不变、输出及积分状态限幅除以 19。电流限幅 0.5 A 不随减速比换算。

原点参考取两台 3508 收到真实反馈后的首次有效低速快照，仅记录一次；不是强制编码器读数为 0。当前启动原点容差为输出轴 ±10 deg，低速门槛为输出轴 0.4/19≈0.0211 rad/s，均需结合机械情况实测确认。Z 键长按达到 2 秒时，两个轴均须在各自记录的原点容差内且低速；下降到位由 PD10 判断。
