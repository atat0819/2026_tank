# 龙门架自动流程实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 鼠标右键触发一次五段龙门架动作，各段由微动开关结束，除第二次抬升外按累计角度分段降速。

**Architecture:** `feeder_fsm/gantry_fsm.cpp` 实现不依赖 HAL 的状态机；同名头文件声明输入、输出和状态。`gantry_fsm.hpp` 集中标定和控制参数，`RtosTask/gantry_task.cpp` 采样、闭环、发送。接入现有 FDCAN3 接收回调，右键不再请求键鼠视觉模式。

**Tech Stack:** C++17、STM32H723 HAL、FreeRTOS、Keil ARMClang；g++ 主机行为测试。

### 1. 状态机

- [x] 先添加 `tests/gantry_fsm_test.cpp` 和运行脚本，确认缺失实现时测试失败。
- [x] 实现空闲→第一次抬升→前伸→第二次抬升→后收→下降→空闲。
- [x] 验证 50%/85% 边界、反向累计角度、第二次抬升原速、每段重置减速档位、长按及忙时点击不排队。
- [x] 验证未标定禁止启动、原点要求、超时、行程异常、双升降进度差及反馈丢失。

### 2. 硬件接入

- [x] PA0/1/2/3/4 对应第一次抬升/前伸/第二次抬升/后收/下降，输入下拉、高电平有效、20ms 消抖；同步 GPIO 和 IOC。
- [x] FDCAN3 接入 0x205、0x206 和 9，快照包含首次收包标志及时间戳。
- [x] 3508 速度 PID，静止轴角度保持；DM4310 MIT 速度阻尼闭环，静止时由累计角度误差生成速度。参数未填写禁止运行。
- [x] 右键使用现有消抖输入；移除右键长按视觉请求。完成后需要松开再按；退出键鼠/遥控掉线停止。
